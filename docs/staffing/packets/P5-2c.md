## 1. Zero-success routes are not rungs (module)

`_derive_class_ladder` currently ranks any route with `comparison_eligible: true`, so a
route with `n>=5` and `verified_pass == 0` becomes a rung (live example: the review class
ranks a route with `pass_rate=0.0` at position 0). A rung's ordering key is mean marginal
cost **among verified-success attempts**, which does not exist without a success. Change:
routes with `verified_pass == 0` go to a new per-class list `excluded_routes:
[{route_id, n, verified_pass, reason: "no verified success"}]` and are never rungs. If no
route remains, `evidence_status` is `"insufficient evidence, hand ladder retained"` and
`rungs` is empty (keep `excluded_routes` populated). Routes with successes but no usable
cost keep their rung with `mean_cost_usd_marginal: null`, sorted after priced rungs (existing
behaviour), and the text diff renders them as `cost=unknown` instead of `cost=None`. Make
sure `write_derived_ladders` writes `excluded_routes` and `render_ladder_diff` shows them
under the class (`excluded: <route_id> (n=.., verified_pass=0)`).
