## What to build

### 1. `scripts/harvest_failed_packets.py` (router)

A stdlib-only CLI (`argparse`, `json`, `hashlib`, `pathlib`, `datetime`; you may import
`lee_llm_router.staffing.ledger.read_attempts` / `resolve_attempts_path` and
`lee_llm_router.staffing.rollup` helpers — reuse, do not re-implement the ledger reader).

Behaviour:
- Read the attempt ledger (`resolve_attempts_path()` default; `--ledger PATH` override).
- Select **production** attempts only: `record_kind == "router_run"` (never `benchmark_run`,
  which is benchmark evidence, and never `agent_orch_attempt`, which carries no packet text),
  `captured_at` within the last `--days` (default 30, relative to `--now` ISO date or today),
  and either `verdict == "fail"` (also accept the dict verdict shape whose `status` is `fail`,
  see §1's two verdict shapes) or `failure_class == "capability_rejected"`.
- Group by `(packet_id, class_record.class_key)`. Per group print: packet_id, class_key,
  attempt count, distinct `router_event.route_id`s, distinct `failure_class` values, first and
  last `captured_at`, `oracle_cmd`. `--json` emits the same as a list.
- **Packet text resolution.** `packet_id` is `sha256:<hex>` of the dispatched packet text
  (`run.py` line ~938: `hashlib.sha256(packet_text.encode("utf-8")).hexdigest()`), not a path.
  Resolve it by hashing every `*.md` under `--packet-dirs` (repeatable; default
  `docs/staffing/packets`) and matching the digest. Unresolved packets are listed with
  `briefing: unresolved (no file under --packet-dirs hashes to this id)` and are **not**
  emitted as skeletons; never paraphrase or invent briefing text.
- `--emit DIR` writes one skeleton per resolved group under
  `DIR/<harvest-id>/v1/` where `<harvest-id>` = `h-<first 12 hex of packet sha>-<class_key with '/' and '+' replaced by '-'>`:
  - `manifest.json`: `schema_version: "pilot-packet/1"`, `task_id: <harvest-id>`,
    `task_version: "v1"`, `role` (benchmark role name via the inverse of
    `escalation-ladders.json` `role_aliases`: `impl`→`implementation`, `review`→`reviewer`,
    `plan`→`planner`; other roles → stop and report), `difficulty_intent: "production-failure"`,
    `design_target_minutes: null`, `origin_kind: "harvested-production-failure"`,
    `origin_ref: "lee-llm-router attempt ledger <packet_id>"`,
    `origin: {repository_label: "lee-llm-router", commit: null, parent_commit: null,
    observed_files: [<the packet's Owned paths lines, verbatim strings>], source_lines: null,
    evidence_summary: "<n> failed production attempts, failure classes <...>, routes <...>",
    reconstruction_deviations: ["skeleton: no repo archive, start_commit, or private evaluator yet; a human freezes the fixture before this packet is run"]}`,
    `repo_path: null`, `start_commit: null`, `repo_archive_sha256: null`,
    `visible_inputs: [{path: "briefing.md", sha256: <sha256 of briefing.md bytes>}]`,
    `environment`, `protocol` copied from `packets/stale-surface/v1/manifest.json` with
    `candidate_cannot_read: []`, `output_contract: {required: "<packet's Oracle line>",
    verification: <oracle_cmd from the ledger>, evaluation_schema: "pilot-evaluation/1",
    acceptance_is_not_model_ranking: true}`, `class`: the ledger's `class_record`
    verbatim (all six fields), and an additive `harvest` block `{packet_id, attempt_ids,
    routes, failure_classes, first_captured_at, last_captured_at, harvested_at}`.
  - `briefing.md`: the resolved packet file's text, byte-for-byte.
  - `oracle.txt`: the `oracle_cmd` string, one line.
- Exit 0 always on a clean read; exit 2 if the ledger is missing/unreadable (message on stderr).
